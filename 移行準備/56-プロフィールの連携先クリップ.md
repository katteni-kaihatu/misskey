# プロフィールのクリップ一覧

プロフィールのクリップタブに、連携済みの両アカウントの公開クリップを表示する。

- ローカルは users/clips、連携先は既存の gridspace/content から取得する。
- 連携先の取得には、対象プロフィールから解決したアカウント ID を使う。解決できない場合は他のユーザーの一覧へフォールバックしない。
- 非公開クリップ、停止・削除済みアカウントのクリップは連携先から返さない。
- 通常のクリップカードを共用し、新しい順・古い順、日付指定、ページ送り、引っ張って更新に対応する。
- 連携先のカードは /clips/:id/linked を開く。片方の取得失敗時は取得できた一覧を残して再試行を表示する。
- 既存のページ・ギャラリーとの互換性を維持するため、古い相手から clips が返らない場合は空配列として扱う。

検証: backend content テスト、frontend profile clips と共通ノート一覧のテスト、変更ファイル lint、生成 SDK、両サーバーの本番表示。
